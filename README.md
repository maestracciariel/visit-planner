# מתכנן ביקורים

קוד המסכים של אתר מתכנן הביקורים (Google Sheets + Apps Script).

- `index.html`: המסכים. האתר טוען את הקובץ הזה מכאן בכל פתיחה, ולכן עדכון כאן מגיע לאתר אחרי רענון (עד כ-5 דקות).
- `Code.gs`: עותק לגיבוי של קוד השרת. הקוד שרץ בפועל נמצא בעורך Apps Script.

אין כאן נתונים: הלקוחות, הביקורים והקווים נשמרים רק בגיליון הגוגל הפרטי.
