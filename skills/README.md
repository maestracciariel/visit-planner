# מיומנויות (Skills) של מתכנן הביקורים

חמש מיומנויות ל-Claude שעובדות עם האתר והגיליון. כל תיקייה היא מיומנות, ובה `SKILL.md`.

| מיומנות | מה היא עושה |
|---------|-------------|
| `visit-planner-site` | תחזוקה ושינוי של האתר (Code.gs + index.html) |
| `import-clients-from-excel` | ייבוא לקוחות מאקסל לפורמט הגיליון, עם מיקום ברמת יישוב |
| `visit-summary` | סיכום ביקור חופשי → שורה בגיליון הביקורים |
| `who-is-waiting` | דוח פעולות המשך פתוחות ולקוחות מוזנחים |
| `build-daily-route` | בניית קו נסיעה יומי עם קישורים לגוגל מפות ו-Waze |

**מקור:** הועברו מ-`~/road-map` במחשב של אריאל (15/11/2026), בלי שינוי תוכן.
**הערה:** `import-clients-from-excel` מזכירה את `scripts/build_data.py` ו-`scripts/make_seed.py`. הם לא במאגר הזה.
**המאגר ציבורי:** אסור להכניס לכאן נתוני לקוחות, מזהי גיליונות או סודות.
