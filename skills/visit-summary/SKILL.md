# סיכום ביקור

## פלט: שורה אחת לכל ביקור, בעמודות של גיליון "ביקורים"
| שדה | איך ממלאים |
| --- | --- |
| תאריך | היום, אלא אם נאמר אחרת (yyyy-mm-dd) |
| businessId / שם העסק | התאמה לשם בגיליון "עסקים". אם אין התאמה ברורה, שאל, או הצע להוסיף עסק חדש |
| תוצאה | ביקרתי / הבעלים לא היה / היה סגור / שיחת טלפון |
| כפתורים | מתוך: השארתי טעימות, הצגתי מוצר, נתתי מחירון, קיבלתי טלפון, ביקשו הצעת מחיר, הזמינו, דיברתי עם הבעלים, דיברתי עם עובד. מופרדים ב-" \| " |
| מה נאמר | 1 עד 3 משפטים קצרים בגוף ראשון, בלי לאבד עובדות (שמות, מחירים, מוצרים) |
| פעולת המשך | פעולה אחת ברורה ("לחזור עם טעימות שוקו"). אם נאמר "לא שווה לחזור", השאר ריק ושנה מצב ל"לא מעוניין" |
| תאריך המשך | המרה של ביטויים: מחר = +1, שבוע הבא = +7, עוד שבועיים = +14, חודש = +30, "יום שלישי" = יום שלישי הקרוב |
| התעניינות | חם / פושר / קר, רק אם יש לזה רמז ברור בטקסט |
| המשך פתוח | כן אם יש פעולת המשך |

## שינוי מצב העסק (גיליון "עסקים")
- "סגרנו", "הזמינו בפעם הראשונה" אצל עסק חדש: סוג = לקוח קיים, סטטוס = פעיל
- "לא מעוניינים", "לא שווה לחזור": לא מעוניין (אדום)
- "העסק נסגר", "לא קיים יותר": נסגר (שחור)

## כללים
- הצג למשתמש את השורה לאישור לפני שכותבים.
- לא להמציא פרטים שלא נאמרו.
- שם איש קשר או טלפון חדש שנאמר בביקור: הצע לעדכן אותם גם בגיליון "עסקים".
